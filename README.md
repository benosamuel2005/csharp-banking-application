# C# Banking Application

A banking application developed using C# and SQL as part of my BSc (Honours) in Computing at Dublin Business School.

## Project Overview

This academic project explores banking application development using a layered software architecture, separating the user interface, business logic, data access and testing components.

## Technologies Used

- C#
- .NET
- SQL / T-SQL
- Visual Studio
- Object-Oriented Programming (OOP)

## Project Structure

- `BankingApp.BLL` — Business Logic Layer
- `BankingApp.DAL` — Data Access Layer
- `BankingApp.UI` — User Interface
- `BankingApp.Tests` — Application testing
- `Database` — Database-related files
- `ClassLibrary1` — Additional class library

## Skills Demonstrated

- Object-Oriented Programming
- Layered Application Architecture
- Separation of Concerns
- Database Integration
- Software Testing
- C# Application Development

## Project Status

Academic coursework project. The repository contains the application source code, database files and testing components.
